## 項目ごと

### 01 ソラモビーム（SK05）
- 原因（実測＋コード）：光線の根元を「体の範囲（bbox）の前の端から 8%・上から 40%」で見積もっていた（js/battle/art25d.js の beam）。発射の姿 05_02 の実際の口先は（436, 252）＝見積もりと 10〜20px ずれ。さらに前回、光線を次の区切り（口を閉じた反動の姿 05_04）まで延ばしたため、姿勢が変わると根元が頬・顔の外に残った。
- 修正：口先の表 `MMTUNE.MOUTH`（js/battle/move-tune-1015.js。コマの絵を拡大して測った画素）→ art25d の `mouthPt`（本体の img と同じ式＝左上・反転 scaleX・回転・中心が原点）で画面の位置へ。光線は発射の姿（05_02）の区切りだけ（t[1,1]）。色・太さ・伸び方は同じ。
- 確認：01_02_04_05_mouth_before_after.jpg（同じ時刻の修正前／後・緑の十字＝口先）、01_02_04_05_mouth_freeze_after.jpg（発射の瞬間で止めた絵・自分側／相手側）。BTB-5（根元と口先の差 2px 未満・自分側／相手側／?mmSize=1）。
- 残るリスク：口先は手で測った値（±3px 程度）。

### 02 スターダストレイ（SK08）
- 原因：01 と同じ見積もり。光線は2区切り（08_04 本命の発射・08_05 撃ち続ける姿）にまたがり、1つ目の姿の位置のまま伸ばしていた。
- 修正：区切りごとに光線を出し直す（08_04＝(315,214)・08_05＝(266,203)。2本目は伸びきった長さで始める＝途切れない）。ソラモビームとは別の時間軸（データの区切りが別）。**光線の絵は今も 05_03（ソラモビーム）の流用＝暫定**。専用の光線（2枚の PNG）が届けば `MOVES['soramo_moves_1012/08_01.webp'].addFx` の `f` を差し替えるだけ（口先の計算はそのまま効く）。
- 残るリスク：2区切りの境目の 60ms は2本が重なって薄く見える（体のコマの切り替えと同じ）。

### 03 スターフォール（SK09）
- 原因：fight()（Phase 6）が当たりのたびに技の絵文字（SK[9][4]＝🌠）を相手の上に出す（index.html の `pop(1-s, sk[4], "sk")`）。iPhone では 🌠 が四角い額の絵＝着弾の上に四角い星（03_starfall_iphone_before.jpg）。Chromium には 🌠 の絵が無いので画面では見えず、DOM（span.sk の追加）で確認した。
- 修正：技のコマで見せている間（MM25D が受け持つ技）だけ、スターフォールの絵文字の札を出た直後に消す（`MMTUNE.EMOJI_OFF`・MutationObserver）。fight()・技のデータの絵文字・ほかの技の絵文字は変えない。星の降り・ダメージ・ヒットストップ・戻りはそのまま。
- 確認：実戦（STOP）で修正前は span.sk「🌠」が残る／修正後は消える。BTB-6。
- 気づいた点（変えていない）：ほかにも iPhone で写真のような絵に見える可能性のある絵文字がある（🎵⏳🔩🐦🍃💢👁️💠🎯🌪️🌫️🗻👊🦶💪🪨🔨💎⛰️🌋 など）。消すかどうかはユーザーの判断待ち。

### 04 ファイアボール（SK15）
- 原因：火球の切り出し（15_02_fx の中の範囲）の中心から飛ばしていた＝絵の火球はガウルの首〜胸の位置に描かれている（中心 約(290,227)、嘴の口先は (567,207)）。
- 修正：`fromMouth`＝その区切りのコマ（15_02）の口先で小さく（0.3倍）生まれて、相手の胸で 1.0倍。
- 確認：01_02_04_05_mouth_freeze_after.jpg（+0ms・+60ms・+140ms・相手側も）。BTB-2・BTB-5。

### 05 フレアレイ（SK16）
- 原因：根元を「16_02 の体の範囲の割合（0.95, 0.34）」で決めて、2区切り目（16_03・姿勢が違う）も同じ位置のまま。絵の光線の根元（497,208）も実際の口（510,221）より上の頬の位置。
- 修正：区切りごとに口先（16_02＝(510,221)・16_03＝(500,215)）から出し直す。transform-origin は 0 50%（根元）・位置 → 回転 → 伸びの順。全体の固定オフセットではなく、コマごとの値。
- 確認：01_02_04_05_mouth_freeze_after.jpg。BTB-5（自分側・相手側・?mmSize=1）。

### 06 聖なる炎（SK19）
- 原因：三色の炎の輪（sp_aura2）を「launch＝相手の胸まで飛ばす」にしていた（前回の修正）。相手の当たりも同じ輪の絵（sp_aura1）を相手の上に重ねていた。
- 修正：輪は2つとも、その区切りのコマ（浮いた姿）の体の中心から外へ広がるだけ（`at:'aura', onBody:true`。相手へ動かない・相手まで届かない大きさ）。相手の当たりは別の表現＝共通演出の正式素材 bc06_hit。そのあと金の加護 → 着地 → 待機は従来どおり。
- 確認：06_holyflame_before_left_after_right.jpg（左＝修正前・右＝修正後）。BTB-7。
- 動画の最後の「青い球＋白い三角」：fight() の能力アップの印（index.html の efBurst＝青い丸の光と ▲。聖なる炎の自分の能力アップで出る）。**報告だけ・消していない**。

### 07 蒼刃乱舞（SK28）
