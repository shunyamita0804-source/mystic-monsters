## 1. 結論（先に読む）

1. **3ルートは別のグラフ**（区間の並び・接続・分かれ道の種類の順・本線の歩数が互いに違う。tests/ch2-routes-1015.test.mjs の C2-03 で監視）。建物・島・海底・塔・会場の**位置は3ルート共通**＝道（橋・桟橋・回廊・遺跡の通路）だけがルートごとに違う。これで素材を3倍にしない。
2. **A／B／C とも「港（海岸）→ 海上 → 潮の塔で海底へ → ガラス回廊／沈没遺跡 → 螺旋塔で海面へ → 会場前 → 大会」を必ず通る**（LOWER_GATE＝潮の塔と RIVAL を通らずに GOAL へ行けない＝検査済み）。
3. **本線の歩数は 93〜132（A）・98〜122（B）・94〜127（C）**＝Chapter 1 A（97〜122）と同じ帯に収めた。40ターン・D6 で歩ける長さにするため、**地点数は 216〜256**（依頼の初期目標 280〜320 には届かない。理由と対策は §6）。
4. **公平性（同じ seed・同じ方針の小規模シミュレーション 600 seed×2体）**：40T 以内の GOAL 到達率 A 55.2%／B 49.7%／C 56.3%（Chapter 1 A 50.7%）、6能力の合計上昇 A 276／B 286／C 286（Ch1 288）、固定報酬の取得率 A 7.6%／B 9.5%／C 10.4%（Ch1 7.7%）。**B は A より −5.5pt**（目標 ±3pt を少し超える）＝B の最初の小さな分かれ道を外すか、B の歩幅をもう少し広げるかの判断が要る（§7 論点 2）。数値の意味と限界は `COMPARISON.md` §3。
5. **ライバルの位置**：本線に対して A 53〜73%・B 63〜72%・C 64〜78%。設計目標 50〜70% は「最短の安全な道」だけ 2〜8pt 超える（Chapter 1 A も 63〜79%）。§7 論点 1。
6. **必要な新しい絵は最小で 24 種類**（地面 4・道と塔 6・海面の建物 11・海底 7・環境 4。うち「最優先」8）。旧 Chapter 2 の 11 背景は**俯瞰図 1 枚（A＝そのまま）以外は使わない（D）**（ユーザー指示 2026-10-15 夕：旧背景10枚は過去のもの）。Chapter 1 の正式マス・サイコロ・UI・HUD は**すべてそのまま**（Chapter 2 専用 UI は不要）。
7. 限定試作：`?chapterBoard=roadfirst&rfData=ch2&ch2route=A|B|C&rfView=world`。保存は `mmrf_proto_ch2_<route>_v1`（通常のセーブ・Chapter 1 の試作の鍵には書かない＝CP-B2 で確認）。絵は無い＝区域の仮の色＋「素材待ち：town」などの開発表示（正式アートではない）。**main 未改変・公開なし・iPhone 実機は未確認**。

## 3. 3ルートのグラフ（構造）

役割の語彙・通行条件・停止の規則は Chapter 1 の原本（MMRF_CORE）と同じ＝**進行のコードを変えずに動く**：
サイコロ 1〜6・40ターン／自由な分かれ道（J0・J1・H）はプレイヤーが選ぶ／運命の分かれ道（Q）はイベントのサイコロ（奇数＝左・偶数＝右）／特殊挑戦（CHALLENGE）は 5・6 で成功／固定報酬（6）＋隠れ家（1・出発時に開閉 50%【仮】）は行き止まり＝帰りもサイコロ・1回の育成で1回／Q・ライバル・特殊挑戦・行き止まりで止まり残りの目は捨てる／門（潮の塔・遺跡の門）は通り抜け。

固定報酬の**地点 ID と効果は Chapter 1 と同じ枠**（L_CHEST・R_CHEST＝150G、L_ALTAR＝全能力 +10、L_LATE_ALTAR＝全能力 +15、REWARD5＝空腹 −50＋100G、R_SPECIAL＝得意な能力 +30、RANDOM_DEN＝200G。値は js/proto/roadfirst-play.js の TUNING.rewards【暫定】）。名前だけルートの景色に合わせる（spec の rewardTitles。仮案）。

### A「港と大橋の王道」（256地点・298接続・41区間）
港の桟橋広場 J0 で**自由に**左（浜の小島伝い：灯台の寄り道）／右（白い大橋：貝殻の祠・神殿島の寄り道）→ 潮の塔の島で合流 → 潮の塔（下降）→ ガラス回廊の入口 Q（**運命**：左右の回廊）→ 回廊の出口 R → **ライバル**（塔の門前）→ 遺跡の門 → 螺旋塔の斜路 → 頂上 H（**自由3択**：桟橋＝最短／西の海門＝**特殊挑戦**（成功＝近道＋西の白塔の祭壇の寄り道、失敗＝西の島々を大回り）／海神像の島＝隠れ家・海神像の恵み・珊瑚の秘宝の寄り道）→ 会場前の桟橋 → 大階段 → GOAL。
Chapter 1 と同じ「自由 → 運命 → 自由3択」の骨格を、海面 → 海底 → 海面の高低差に乗せた王道。本線 93〜132歩・ライバル 66〜74歩（53〜73%）。

### B「島めぐりの浅瀬」（216地点・269接続・36区間）
港を出てすぐ J0（**自由**：浜の飛び石／港の桟橋＝短い輪）→ 浜の合流 M1 → 岩門の島 J1（**自由**：灯台回りの小島伝い＝灯台の寄り道／大橋から神殿島＝神殿島の寄り道）→ 潮の塔の島で合流 → 潮の塔（下降）→ 右の回廊を抜けて沈没神殿の**封印の扉＝特殊挑戦**（成功＝神殿の奥（宝物庫の寄り道）を回って塔の門前へ／失敗＝短い迂回）→ **ライバル** → 螺旋塔 → 頂上は**潮流の運命の分かれ道**（奇数＝西の島伝い：西の白塔の祭壇の寄り道／偶数＝東の海神像の島：隠れ家・恵み・秘宝）→ 会場前の桟橋 → GOAL。
分かれ道の順が「自由 → 自由 → 特殊挑戦 → 運命」＝A と逆。海面が長く海底が短い。本線 98〜122歩・ライバル 65〜84歩（63〜72%）。歩幅を少し広め（27単位。A・C は 24）にして本線を 40ターンに収めた。

### C「沈没遺跡の回廊」（232地点・277接続・37区間）
港から白い大橋をまっすぐ（貝殻の祠・神殿島の寄り道）→ 潮の塔（下降）→ すぐ海底の分かれ道 J1（**自由**：ガラス回廊＝運命の分かれ道 Q を含む短い道／西の崩れた列柱の回廊＝長い道：西の遺跡の祭壇の寄り道・**封印の間の特殊挑戦**（成功＝宝物庫の寄り道、失敗＝短い戻り））→ どちらも塔の門前で合流 → **ライバル** → 螺旋塔 → 頂上 H（**自由2択**：桟橋／海神像の島）→ GOAL。
海面が短く**海底が本線の半分以上**（117歩分の区間）。本線 94〜127歩・ライバル 69〜88歩（64〜78%）。

区間ごとの歩数・本線の内訳は `COMPARISON.md` §1。地点 ID の付け方は Chapter 1 と同じ `{区間}_{番号}`（例 `EL01_03`）。

### (d) 道路モジュール・海上と海底の見せ方・負荷
- **道**：Chapter 1 と同じ「地点の並びから engine が帯を描く」方式（strip の絵を道筋に沿って並べる）。橋も回廊も遺跡の通路も**同じ仕組み・絵だけ違う**（海面＝白石の橋 R-01、海底＝苔むした石畳 R-03）。固定の一枚絵に道を焼き込む方式は採らない（3ルートで道が違う＝一枚絵なら背景が3倍になる。Chapter 1 の HQ 化で「道の形は変えずに絵だけ差し替える」仕組みが実証済み）。
- **海面と海底**：1枚の盤の上では**区域（多角形）で塗り分ける**。海面＝青い水のタイル（G-01）、陸地＝砂と草（G-02）＋波打ち際の帯（E-03）、海底＝暗い砂地（G-03）＋落ち込みのふち（E-04）、ガラス回廊＝床（G-04）＋**前景の天井（U-01・半透明）**。Chapter 1 の「谷・雲海・森」の塗り分けと同じコード（terrainMasks／drawTerrain）に kind を足す。
- **高低差**：盤は平面なので「下りる／上る」は**建物の絵（潮の塔 R-04・螺旋塔 R-05）と道の帯の色の切り替え**で表す。螺旋塔の斜路は塔の足もとを回る12〜13歩の帯（実際の高さはカメラで表せない）。承認論点（§7 の 3）。
- **透明構造と描画順**：モンスターは「道の上（床）」に立つ。欄干・橋脚・珊瑚は床の上の背後の層（z −30）、ガラス回廊の天井だけ前景（不透明度 0.35〜0.5）。モンスターと重なる景物を半透明にする既存の xray をそのまま使えば「天井に隠れて見えない」は起きない。
- **足元の接地**：Chapter 1 と同じ（静止の立ち絵の縦横比で足を地点に合わせる＝既存）。床の絵は真上の模様なので透視のずれは起きない。**建物の絵の足元（下端）が道の帯の高さと合うかは、絵が届いてから地点ごとに確認が要る**（§8 未解決）。
