## 1. 今のカメラ（従来）の何が酔いを起こしているか（確認済）

- `js/chapter/world-board.js` の CAM と MMRF_WORLD の `heading: true, yawTau: 600`：歩く1歩ごとに「今の地点 → 先の4地点の重心」の向きを計算し直し、カメラの向き（yaw）をその向きへ指数で寄せ続ける。
- 1歩 0.24秒で次の目標に変わるので、**歩いている間ずっと回り続け、止まってからも約2秒以上ゆっくり回り続ける**（指数の長い尾）。止まって 2.5秒たっても回転は 0.002〜0.05° ずつ続いていた（フラグなしの比較の記録）。
- 同時に倍率（fitZoom）・横の寄せも1歩ごとに変わる＝景物・建物の絵が「グルーッ」と回って見える原因。

## 2. 試作した方式（URL で切り替え）

| URL | 方式 | 中身 |
|---|---|---|
| （なし） | 従来 | 後ろから追う・歩く間も止まったあとも回り続ける（変えていない） |
| `?qaCam=fixed` | 固定 | 向きを回さない（北が上）。比較用 |
| `?qaCam=c` | **C案** | 歩いている間は向き・横の寄せ・倍率を変えない（足りなければ引くだけ）。止まったとき／分かれ道を選んだときだけ、進む向きとのずれが 50° 以上なら、決まった時間（90°＝0.6秒・180°＝0.84秒・ゆっくり始まりゆっくり止まる）で向きを変えて止める。止まったときの 12px 未満の注視点のずれは追わない（漂わない） |
| `?qaCam=ccut` | C案・切替 | C案と同じ判定で、向きを変えるときは盤を一瞬（0.15秒）暗くして切り替える（回る動きを見せない） |

- 調整：`&qaCamDeg=`（向きを変えるずれの角度・10〜180・既定 50）・`&qaCamMs=`（90° を回す時間・既定 600）。
- 変えていないもの：傾き（ピッチ 40°）・ロール・遠近・マスとモンスターの大きさ・HUD・操作欄（画面に対して正立のまま）・道・マス・判定・セーブ。
- 景物（建物・木）の絵はもともと「いつもカメラの方を向く立て札」＝絵の中の文字や看板は回らない（向きが変わるのは地面と配置だけ）。
