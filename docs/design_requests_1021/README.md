## 指摘ごとの原因と直し方

| # | 指摘 | 調べた結果（原因） | 直し方 | 絵 |
|---|---|---|---|---|
| 1a | Chapter 1：道の横の影が単調でチープ | 影ではなく「注目している道以外を暗くする幕」。幕の明るい帯を、マスを並べ直す**前**の位置で、直線でつないで塗っていた → 描いた道から横にずれ、片側だけに直線のふちの暗い帯が出ていた（全 Chapter 共通） | 幕を、描いた道（曲線）とマスの表示の位置に合わせる。ふちをやわらかくし、暗さを弱める | 不要 |
| 1b | Chapter 1：崖のふち（赤枠）がギザギザ | 崖のふちの帯の絵を、2.5 単位ごとの短い四角に切って向きを変えながら並べていた → 曲がる所で四角のすき間に黒い三角（谷の影）が見え、外側はとがる | 帯を切れ目のない 1 本の帯（曲がり角でつなぐ）で描く。ふちの線をなめらかにし、細かい出っぱりを消す | 任意（G02） |
| 2 | START が丸くない | 円が小さいのは **Chapter 2 B（半径 9.5）と Chapter 4 B（8.8）** の 2 ルート（ほかの 10 ルートは 17〜27）。マスの間隔をそろえる処理が START の円を先に小さくしていた。さらに道が START の後ろへ四角くはみ出していた | START の円は小さくしない（全 12 ルートで同じ大きさ）。間隔は先のマスで取る。START の後ろへ道を出さない | 不要 |
| 3・6 | 門が道に重なる | 門の絵は道をまたぐ 1 本の道の上に立てる前提だが、分かれ道の広場（3〜4 本の道が出る所）に立っている門があり、柱が別の道に乗っていた。**重なる所＝Chapter 1 A／B／C の封印の門・Chapter 4 A／B／C の火の神殿の門・Chapter 2 A／C のガラス回廊の入口・Chapter 2 B の沈んだ神殿の門・Chapter 3 B の白いアーチ（分かれ道の手前）**。柱が道のふちに少しかかる門（Chapter 2 A の閉じた海の門・Chapter 2 A／B／C のライバルの所の門）も同じ規則で直す。Chapter 3 A／C の白いアーチ・Chapter 2 の港の門・下りる門・会場への門は重なりなし | 門は「1 本だけのまっすぐな道」の上に立てる（広場の手前の、入ってくる道の上へずらす）。置ける所がない門は道の脇に置く。今ある正面向きの門の絵で足りる | 不要 |
| 3 | 道のクオリティが低い・画質が粗い（Chapter 4） | 絵の解像度は足りている（2048px）。粗く見えるのは、縁石が石畳とほぼ同じ色で道のふちが分からない・地面が遠くで平らな茶色になる・石が大きく単調なため | 新しい道一式の絵（G01）＋描き方（縁石の明暗・地面の揺らぎ） | **必要（G01）** |
| 4・5 | マスが窮屈 | Chapter 4 A：隙間 3 単位未満が 20 か所・重なり 2 か所。ほかも分かれ道のまわりで詰まる所がある（Chapter 2 C で重なり 1・Chapter 3 B で 1.4 単位など） | 分かれ道の広場のまわりと S 字の道で、マスの間隔を広げる（道を少し延ばす・広場から離す）。マスの数・つながり・歩数は変えない | 不要 |
