# D03 Chapter 2 港の門（正面向き・左右対称の全体）1点

## 使い方
- Chapter 2 の START（港の広場）の出口で、**道をまたいで立つ門**。モンスターはこの門の下をくぐって出発します。
- 今は正式原画（ref_ch2_harbor_gate_official.webp＝斜め向き・右に小屋つき）を、道の脇に置いています。道をまたぐには正面向きの絵が要ります。
- 道の幅は門の絵の幅の約 40%。**アーチの口（柱と柱のあいだ）は絵の幅の 45% 以上**にしてください（道と縁石が柱にかからないように）。

## 仕様
- 大きさ：**横 1280 × 縦 1100 px 程度**（透過 PNG）。
- 正面からまっすぐ（道に対して直角）、少し上から見た絵。**左右対称**。
- 柱の台座（足もと）が絵の下端。植え込み・階段・小屋は付けない（道にかかるため）。
- 柱の外側の面まで描く（左右で切れていない）。
- 正式原画と同じ素材感：白い石の柱・青いドームの屋根・金の装飾・貝の紋章。
