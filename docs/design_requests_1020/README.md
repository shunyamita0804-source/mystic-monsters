## 全部に共通の約束

- **真上から見た正射影（top-down orthographic）**の素材にする（D02 の看板・D03 の門は立てる絵なので、斜め上から見た正面の絵）。
- 透過 PNG は、**本当の透過**にする。市松模様・白い縁・黒い縁を絵に焼き込まない。
- くり返して敷く絵（タイル・帯）は、**継ぎ目なし（seamless）**。帯は横方向にくり返せること。
- 文字・数字・矢印を絵に入れない（ゲームが描く）。
- 既にある正式素材の色・雰囲気に合わせる（`ref/` の参考画像）。モンスターは描かない。
- 原寸の PNG のまま送ってください。ゲームに入れるときに縮小・WebP にします。
- ZIP の名前とファイル名に、依頼の番号（D01 など）と内容を入れてください（例：`Mismon_Design_D01_Ch3Road.zip`・`D01_C3_R1_road_strip.png`）。
