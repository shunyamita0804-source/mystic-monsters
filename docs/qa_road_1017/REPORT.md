## 2. ぼけの原因（数値で分けた）

いちばん寄ったカメラ（C案・倍率 s＝5.6 px／単位）× iPhone の画素比 3 ＝**画面で 1単位あたり 16.8 画素が要る**。

| 段 | 従来 | 新素材＋今回の描き方 |
|---|---|---|
| ① 素材の細かさ（px／単位） | 2.8（R01）〜7.1（橋床）。Ch1 の道の帯 5.6・草地 4.0 | 11.5（R01）・12（草地）・14（海）・16.7（道の帯）・17.8（R1／R2・橋床）・18.3（白石畳） |
| ② 地面を描く canvas（px／単位） | 遠くの層 2（全体）／夜間 QA の近くの層 5 | 遠くの層 2 ＋ 近くの層 **10**（64単位の区画・画面に大きく映る順・上限 40MB） |
| ③ canvas → 画面の引き伸ばし | 16.8 ÷ 2 ＝ **8.4倍** | 近くの層 16.8 ÷ 10 ＝ **1.7倍** |
| ④ 合成（3D に傾けた平面） | 平面の層の中に描かれた canvas は、平面の層の低い倍率で描かれてから引き伸ばされる | **区画ごとに別の合成の層**（`will-change: transform`）＝canvas の画素のまま合成 |
| ⑤ 絵の補間 | 双一次（ミップマップなし） | 同じ |

- **④が今回いちばん大きい発見**：夜間 QA で「近くの層を 1単位 5px→8px にしても鮮明さが 1.15倍で頭打ち」だったのは、素材の細かさではなく④（平面の層の中で低い倍率で描かれていた）が原因だった。Chromium の GPU 描画で、近くの区画の canvas は 1単位 10px でくっきり描けている（canvas を書き出して確認）のに画面ではぼけ、区画を別の層にすると全区画がくっきり映る（`compare/layer_effect.jpg`）。
- 縞模様の計測（`tools/road1017/resolve.mjs`・地面に 0.25〜4単位の周期の白黒の縞を描いて撮る）：遠くの層は 1単位の縞まで（0.5単位は潰れる）、近くの層 10px は 0.5単位の縞まで見分けられる（GPU 描画）。ソフトウェア描画（自動テストの既定）は3D の平面を低い倍率で描くため縞がブロック状に潰れる＝**ソフトウェア描画の画面は画質の判定に使えない**（以後の画像はすべて GPU 描画）。
- iPhone の Safari（WebKit）でも「3D に変形して拡大した層は等倍で描いて引き伸ばす」ためぼけることが知られている＝④の対策が効く見込みだが**実機では未確認**。

## 5. 負荷・メモリ（Chromium・GPU 描画のエミュレーション＝iPhone の数値ではない）

- 近くの層：1単位 10px・64単位の区画（642×642）・上限 40MB（約 25枚）。止まるたびに 14〜25枚。
- 素材のデコード後の大きさ（RGBA）：Ch1＝草地 約 5.6MB＋R 約 2.7MB＋道の帯 約 4.8MB／Ch2＝海 約 7.5MB＋橋床 約 6.6MB（raw）＋白石畳 約 2.4MB＋R01 約 2.9MB。読むのはその景色の物だけ（常時の一括の先読みはしない）。
- 区画1枚を描く時間：ソフトウェアの GPU エミュレーションで 20〜300ms（実機の GPU よりかなり遅い）。描くのは 1フレームに 6ms まで→残りは次のフレーム。歩く間のフレームの時間 95% 点は 16.8〜33ms が多く、区画を描くときに 50〜200ms の落ちが出ることがある（§6）。
- iPhone の進入クラッシュ対策（CR14）の見積もりに近くの層 最大 40MB が上乗せになる＝実機で確かめるまで本番には入れない。

## 6. 残る NG・未確認（正直に）

1. **iPhone 実機は未確認**（PC の Chromium の結果を実機の合格と書かない）。区画ごとの層（④）が WebKit でも同じように効くかは実機で見る必要がある。
2. 近くの層と遠くの層の境目：近くの層が足りない遠くの所（画面の上のほう）はぼけたまま＝くっきり／ぼけの境目が見える所がある。
3. 区画を描くときのフレーム落ち（エミュレーションでは目立つ）。実機で目立つなら、区画を小さく／描く数を減らす／先に描いておく、で調整する。
4. R1 の切れ目の石の崩れ・R2 の半分の石・白石畳の列のゆがみ＝描き方では直しきれない。**完全に消すには、端がつながる形で描いた石畳の絵（美術）が要る**。
5. 欄干（斜め俯瞰）とアーチ（正面寄り）は真上からの地面とパースが合わない＝美術の判断待ち（今回は「重ねて完成に見せる」ことはしていない）。
6. 草地 fix は1枚が小さい分くり返しが増える（揺らぎで緩和したが、遠くから見ると周期が分かる所がある）。
7. 自動テストの既定（ソフトウェア描画）では画質を判定できない＝画質の比較は GPU 描画で撮った画像で行った。
