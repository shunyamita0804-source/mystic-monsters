## 個別の採否案（素材の正式採用はユーザーの判断。今回は本編に入れていない）

| 項目 | 採否案 | 理由・必要なもの |
|---|---|---|
| R1 の継ぎ目の石の崩れ | **帯は作り直しが要る**（面の素材は fix で可） | 2px の混ぜでは石の形がつながらない（禁止事項）。**依頼**：Ch1 R1 の帯 2880×384（横にくり返し・切れ目が目地の上に来る＝石の並びの周期の整数倍）・見本は ch1_strip_r1_raw.webp |
| R2 の端の半分の石 | **帯の端の列を作り直す**（または縁石の位置を目地に合わせる） | **依頼**：Ch1 R2 の帯 2880×384（縁石の際の石が丸ごと＝端の列は完全な石）・見本は ch1_strip_r2_raw.webp |
| 草の周期 | fix＋明暗の揺らぎ（既定）で採用可 | さらに消すなら同じ絵の向き違い2枚の交互（コード側で可能）か、2048px の草の素材 |
| 白い橋（平面的） | 欄干・アーチは採用可・**側面の厚み**が無い | **依頼**：白い橋の側面（厚み）の帯 1552×128（RGBA・横にくり返し）＋橋の下の影。橋床は目地の段違いの作り直し（前回から） |
| 新しい Ch2 の盤 | 保留（ユーザーの採否まで一般プレイは従来の画面） | 景色・地点・接続・固定／レア／ライバル・空腹・大会・時間切れ・セーブの差は docs/ch2_abc_design_1015/DESIGN.md |
