## 2. 置き方（要点）

- スターダストレイ：絵の発光点（x 215/2048・y 280/512）を、そのコマ（08_04・08_05）の口先へ。縦横比はそのまま。A_02 の右端の平らな切り口は相手の奥でマスクで溶かす（表示の処理・絵は変えていない）
- ずつき：B01 溜め → B02 突進 → B02 接触（ヒットストップ 110ms・揺れ）→ B01 戻る。2枚とも足もと y 1140（同じ切り出し）。命中の飾り（31_03_fx1）は額が見えるよう 0.55倍
- ルートテンペスト：根は絵の下 7% を相手の足もとへ（高さ＝相手の体の約1.35倍・相手の前に重ねる）。命中は相手の被弾点（画面の端で切れない大きさ）。当たり＝D03 打撃・D05 開きで1回
- ルートドレイン：08 を正式の待機絵に合わせて10枚とも同じ倍率・足もと（2560 の全幅を画面に収める縮小はしない）。蔦の部分（派生の x ≥ 470）だけ横に伸縮して2つの接触点の中ほどを相手の被弾点へ（腕は足さない・同じ画像の2つの切り出し）。2回の脈動で相手が小さく震える・07 で回復の数字。共通演出のとき約2.9秒（共通演出なしのときは 1.44秒に詰める）
