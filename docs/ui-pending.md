# 素材待ちの UI と差し替え口（2026-10-06）

新しい正式デザイン素材が届いていない UI の一覧です。今は従来の HTML/CSS のままで、勝手な絵は足していません。
素材が届いたら、下の「差し替え口」の CSS（index.html の該当ブロック）で `background:url(...)`／`border-image` を当てるだけにしてあります（処理・押せる範囲・文言は変えない）。
画像は従来どおり `assets/ui/…` に可逆の PNG（表示の約2倍）で置き、README.md に元ファイルと sha256 を書きます。
