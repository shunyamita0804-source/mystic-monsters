# ジオルの技アニメ（2026-10-12・正式採用用・透過補正版 全96枚 1of9〜9of9）

原本（1872×1248・RGBA。キャラ48枚＋エフェクト48枚。原本100枚のうち旧版の重複4枚は制作側で除外済み）はリポジトリに置かない（`sha256.txt`＝原本 96枚の sha256）。作り方は `tools/jiol1012/build.py`（透明な余白を切る → 0.35倍 → WebP 品質86）。緑を抜き直していない・色は変えていない。

- 「キャラNコマ目」と「エフェクトNコマ目」は同じキャンバスの別の層＝同じ技・同じコマ番号を同じ時刻に重ねる
  - 本体の上に重ねる効果（土埃・軌道・溜めの光など）＝技ごとに全コマ共通の範囲で切る（`jNN_MM.webp` と `jNN_MM_fx.webp`。原本の位置合わせ・接地のまま）
  - 別に置く効果＝着弾（tgt＝相手の体）・光線（ray＝自分の胸から相手へ伸ばす）・自分への効果（self）＝その層だけ自分の範囲で切る（`jNN_MM_fx.webp`）
- ファイル名 `jNN_MM`：NN＝正式の技表（js/phase10/monsters.js の OFFICIAL_MOVES.jiol）の番号 1〜10、MM＝コマ
