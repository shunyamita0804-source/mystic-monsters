## 透過化（自動・tools/fx1011/derive.py）
受領した 21枚はすべて RGB の JPEG で、透明の代わりに市松（白 約253／灰 約205〜241）が焼き込まれていた。
1. 白と灰の切り替わりの位置から、市松の1マスの大きさと位相を画像ごとに求める（10.6〜17.5px。白と灰の1組の周期を拾ったときは半分も試す）
2. マスごとの灰色（光に覆われたマスは同じ側の中央値）で、画素ごとの背景色を作る
3. 背景色との差から透明度を出し、色は背景を引いて戻す（color to alpha）。白いマスの上の明るい画素は透明度が決まらないので、灰色のマスで見えている透明度から補間する
4. 画像の縁につながる背景・絵に囲まれた 1.5マス以上の市松の溜まり・境目の細い線のかすを消す
5. FX は、市松と見分けられない薄い白い光（透明度 0.5 未満・無彩色）を弱める
6. 余白を切り詰めて縮小 → WebP（品質86・透過あり）
