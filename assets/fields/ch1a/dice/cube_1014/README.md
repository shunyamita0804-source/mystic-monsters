## そのまま使えたか
A は斜め上から見た1枚の絵で、見えている面は3つ（天面＝紋章・左の面＝2・右の面＝3）。光・影・縁の丸みも1枚に描き込まれている。
回る立方体は6面がそれぞれ正面を向くので、A を1枚のまま回すことはできない（どの向きでも同じ3面しか見えず、出目 4〜6 の面が A に無い）。そこで：

| 面 | 作り方 | A のまま |
|---|---|---|
| 2 | A の左の面を、面の4つの角（目で測った A の画素）から正方形へ戻した（透視の補正だけ）。縁の外へ少し入った白い背景だけ内側の色で埋めた | 目・金の角の飾り・真珠の地・縁の光は A のまま |
| 3 | A の右の面を同じく正方形へ戻した | 同上 |
| 4・5・6 | 地＝2 の面から2つの目を消したもの（OpenCV の inpaint で周りの真珠の地から埋めた）。目＝A の 2 の面の目（右下＝正面に近いほう）を丸く切り出し、普通のサイコロの並びに置いた（面の 24.5% の大きさ） | 地・角の飾り・目の絵は A のもの。並びだけ作った |
| 1 | 地（同上）の中央に、A の天面の紋章（金の輪の円盤）を切り出して置いた。A の絵では上から見た円盤が縦につぶれている（横 328：縦 192）＝縦だけ伸ばして円に | 紋章は A のもの。円に戻しただけ |

新しい絵は描いていない（色・模様の描き足しなし）。旧 cube_1013（Phase 12 の正式サイコロからの派生）はファイルだけ残す。
面の絵に縁の光と角の金の飾りが入っている＝dice-cube.js は面を内側へ寄せず（inset 0・角の丸み 7%）、旧の面取りの帯（.d3-e）と角の丸い飾り（.d3-c）は出さない。角のごく小さなすき間は中の金の芯（.d3-k）でふさぐ。
動き（1.30秒で止まる）・出目・乱数・着地の SE（DICE_CUBE）・タップの操作は変えていない。
