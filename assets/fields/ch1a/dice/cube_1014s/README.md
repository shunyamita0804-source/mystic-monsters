# 立体サイコロの正式の面・対称版（2026-10-14 実機試遊③）

js/chapter/dice-cube.js の skin 'official' が使う6面。`tools/dice1014/faces_sym.py` が cube_1014（開発29（2）の正式デザイン A からの派生）の画素を並べ直して作る（新しい絵は描いていない）。

- 原因：cube_1014 は 2・3 の面が斜めの絵を透視の補正で戻したもの＝面の中で目の大きさがそろわず（3 の面＝66／73／76px）、角の金の飾りも面ごとに形が違った。立方体に組むと角・面が「ねじれ」「台形」に見えた。

- 目＝4 の面の目を丸く切り出して 0.9 倍（59px）にし、普通のサイコロの升目（中心から ±64px）に置いた（1〜6 で同じ大きさ）。
- 1 の面＝cube_1014 の 1 の面の紋章（金の輪の円盤）を中央へ。
- あわせて着地で縦横の比を変える動き（つぶす）をやめた（大きさだけ小さく弾む）。動き・1.30秒・出目・乱数・SE は変えていない。cube_1014 はファイルだけ残す。
