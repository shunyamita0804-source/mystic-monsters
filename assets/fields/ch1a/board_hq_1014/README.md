## パターンごとの使い方（js/proto/roadfirst-world.js の SKIN 'hq1014'）

描くときにファイル名を読み替えるだけ。地点・道の形・谷／雲海／森の範囲・景物の位置と数と割合（scatter・waterProps・peaksOf）は変えていない。

| | A はじまりの草原 | B 花と清流の草原 | C 岩丘と遺跡の草原 |
|---|---|---|---|
| 草地（ART.ground・草地の外の帯） | A1 | A2 | A3 |
| 道の帯・分かれ目と行き止まりの敷石の円 | R1 | R1 | R2 |
| 谷の中の水（川） | W1 | W1 | W2 |
| 木（prop_tree） | T1 | T2 | T1 |
| 岩（prop_rock）→ 岩柱（幅 ×0.85） | RP1 | RP1 | RP2 |
| 遺跡の岩柱（rock_pillar・C だけ） | — | — | RP1 |
| 小花（prop_flowers） | F1 | F2 | F1 |

13点すべて、どれかのパターンで画面に出る。変えていない絵：谷底・雲海・崖や岸の帯・森の樹冠・針葉樹・茂み・苔岩・石柱・葦・睡蓮・滝・岩峰・目印・大会会場・マス。

- 敷石の円（分かれ目・行き止まり）は円の中心に R の中央を合わせて描く（R の1枚は 57.5単位＝円より大きい）＝R2 の上下のつなぎ目が円の中に入らない。
- 読めない絵（404 など）は従来の `assets/proto/board_art_1010/` の絵へ戻す（景物は幅も従来の値）。
- 見比べ・戻すとき：URL に `?boardSkin=1010`（または `window.MM_BOARD_SKIN='1010'`）で従来の絵。すべてやめるときは js/chapter/world-board.js の `skinKey` が null を返すようにする。

## 限界（報告）

- 地面（草・道・水）は canvas に 1単位 2px で描いている（従来どおり）。近景のカメラでは約3倍に拡大されるので、新しい草・石の細かい描き込みは近景ではぼける（従来の絵も同じ）。景物（木・岩柱・花）は画像のまま描くので近景でもはっきり見える。
- R1 の帯は長さの向きの切れ目（640px ごと）で、石が1つ「く」の字に見える所がある（画面では 23単位の幅の帯の中の小さな石）。
- W1／W2 は湿地（水と草の斜めの帯）＝谷の中の川は「湿地の川」に見える。
